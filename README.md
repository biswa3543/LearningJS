
# 🚀 My JavaScript Learning Journey

Welcome to my JavaScript learning repository! I am using this space to track my progress, store notes, practice coding, and showcase mini-projects as I learn JavaScript.

## 🎯 Learning Goals
- Master core JavaScript concepts (Variables, Data Types, Functions, Objects, Arrays).
- Understand DOM manipulation and how to make web pages interactive.
- Learn modern ES6+ syntax and features.
- Grasp Asynchronous JavaScript (Promises, Async/Await, Fetching APIs).
- Build small, practical web applications.

## 📂 Repository Structure

Here is how my learning materials are organized:

*   **`/01-basics`**: Fundamentals like variables, loops, and conditional statements.
*   **`/02-functions`**: Standard functions, arrow functions, and closures.
*   **`/03-data-structures`**: Working with Arrays and Objects.
*   **`/04-dom-manipulation`**: Selecting elements, changing styles, and event listeners.
*   **`/05-async-js`**: API calls, JSON, and handling asynchronous operations.
*   **`/projects`**: The fun stuff! Mini-projects built to solidify my learning.
